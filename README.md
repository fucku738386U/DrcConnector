# 💀 DrcConnector

**Remote Desktop + SSH Terminal | Dark UI | Smooth | Android 14**

A powerful Android application that combines remote desktop connectivity with a built-in SSH terminal — all wrapped in a sleek, dark-themed interface.

## Features

- 🔗 **SSH Terminal** — Full-featured SSH client with session management
- 🖥️ **Remote Desktop** — VNC/RDP connection support
- 🌑 **Dark UI** — OLED-friendly pure black theme with accent highlights
- ⚡ **Smooth** — Optimized for Android 14 with modern Material You design
- 🔐 **Secure** — Key-based auth, password vault, encrypted storage
- 📱 **Adaptive** — Phone & tablet layouts

## Tech Stack

- Kotlin + Jetpack Compose
- SSHJ (SSH client)
- Material Design 3 (Dark theme)
- GitHub Actions CI/CD

## Build

APK auto-built via GitHub Actions on every push to `main`.

```
./gradlew assembleRelease
```
